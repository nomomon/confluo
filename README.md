<h1 align="center">Confluo</h1>

<p align="center">Every pull request, one calm place.<br>GitHub and GitLab (Azure DevOps soon) in a native macOS app.</p>

## Install

```sh
scripts/install-macos.sh
```

Uses your existing `gh` / `glab` logins. No tokens to paste.

## What it does

- Inbox of PRs and MRs that need you, across providers
- Read, review and comment on diffs, line by line
- Projects from a folder, a repo URL or a whole group

## CLI

```sh
gv list --needs-you
gv show <pr-url>
```
