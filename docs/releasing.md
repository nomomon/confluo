# Releasing

Tagging `vX.Y.Z` runs `.github/workflows/release.yml`: a universal build, signed with your Developer ID,
notarized and stapled, published as a GitHub release with `Confluo-X.Y.Z.dmg`, `Confluo-X.Y.Z-macos.zip`
(used by the in-app updater) and `SHA256SUMS`. Notes come from Conventional Commits since the previous tag.

## Without Xcode

Create the certificate with OpenSSL and the browser:

```sh
openssl genrsa -out devid.key 2048
openssl req -new -key devid.key -out devid.csr -subj "/emailAddress=<apple id>/CN=<name>/C=<country>"
# developer.apple.com > Certificates > + > Developer ID Application (G2 Sub-CA), upload devid.csr, download the .cer
openssl x509 -inform DER -in developerID_application.cer -out devid.pem
openssl pkcs12 -export -legacy -inkey devid.key -in devid.pem -name "Developer ID Application" -out devid.p12
openssl x509 -in devid.pem -noout -subject   # identity for APPLE_SIGNING_IDENTITY
```

The API key comes from App Store Connect > Users and Access > Integrations > Team Keys (Developer role).

## One-time Apple setup

Needs a paid Apple Developer Program membership.

1. **Developer ID Application certificate.** Xcode > Settings > Accounts > Manage Certificates > `+` >
   Developer ID Application (or developer.apple.com > Certificates > `+` > Developer ID Application, with a CSR
   from Keychain Access).
2. **Export it as .p12.** Keychain Access > My Certificates > right-click "Developer ID Application: ..." >
   Export, pick a strong password. The identity name is the certificate's full name:
   `security find-identity -v -p codesigning` prints it, e.g. `Developer ID Application: Your Name (TEAMID)`.
3. **App Store Connect API key.** appstoreconnect.apple.com > Users and Access > Integrations >
   App Store Connect API > Team Keys > `+`, role **Developer**. Download `AuthKey_XXXXXXXXXX.p8` (only once),
   note the **Key ID** and the **Issuer ID** shown above the list.

## GitHub secrets

```sh
gh secret set APPLE_CERT_P12_BASE64 --body "$(base64 -i DeveloperID.p12)"
gh secret set APPLE_CERT_PASSWORD     # the .p12 export password
gh secret set APPLE_SIGNING_IDENTITY --body "Developer ID Application: Your Name (TEAMID)"
gh secret set APPLE_API_KEY_BASE64 --body "$(base64 -i AuthKey_XXXXXXXXXX.p8)"
gh secret set APPLE_API_KEY_ID --body "XXXXXXXXXX"
gh secret set APPLE_API_ISSUER --body "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
gh secret set KEYCHAIN_PASSWORD --body "$(openssl rand -base64 24)"   # temp CI keychain
```

## Cut a release

```sh
# 1. bump `version` under [workspace.package] in Cargo.toml, then:
cargo check -p gv-desktop          # updates Cargo.lock
git commit -am "chore(release): v0.1.0"
git tag v0.1.0
git push origin main v0.1.0
```

The workflow fails early if the tag does not match `Cargo.toml`. Watch it with `gh run watch`.

## Locally

```sh
scripts/release-macos.sh           # host arch only, ad-hoc signed unless the APPLE_* env vars are set
UNIVERSAL=1 scripts/release-macos.sh  # arm64 + x86_64 (heavy on 8 GB; CI does this)
scripts/make-dmg.sh                # dmg from target/release/Confluo.app
scripts/release-notes.sh v0.1.0    # preview the notes
```

Signing locally: export `APPLE_SIGNING_IDENTITY`, and for notarization `APPLE_API_KEY_PATH` (the .p8 file),
`APPLE_API_KEY_ID` and `APPLE_API_ISSUER`. The dmg background is generated by
`scripts/brand/generate_dmg_background.py`.

## Updater

The app asks `api.github.com/repos/nomomon/confluo/releases/latest` on launch and every 6 hours
(unauthenticated, ETag). A newer version shows a card in the sidebar. Installing downloads the zip, checks it
against `SHA256SUMS`, runs `codesign --verify --deep --strict`, requires the same Team ID as the running app
(when that is Developer ID signed), swaps the bundle and relaunches. To test an install from a local `dist/`,
see `crates/update/tests/local_install.rs`.
